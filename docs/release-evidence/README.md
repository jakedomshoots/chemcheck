# ChemCheck Release Evidence

Store dated, non-sensitive release evidence here. Do not commit customer data, API keys, screenshots containing gate codes, or raw production logs.

Each release candidate requires:

- exact commit and branch/tag;
- test, lint, build, dependency, and E2E summaries;
- offline/two-user/two-tech evidence;
- export/delete/restore fixture evidence;
- security scan and privacy-manifest review;
- Xcode archive, App Store validation, TestFlight, and device-matrix evidence;
- provider webhook/payment delivery evidence using test data only;
- known-risk register, incident owner, and rollback instructions.
